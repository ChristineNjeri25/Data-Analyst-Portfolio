# Healthcare Projects

## 1. Patient Intake Form (KoboCollect / ODK)
- **Objective:** Design a digital data collection form for field nurses to capture patient intake data without paper.
- **Skills Used:** KoboCollect form builder, data validation logic, and single-choice inputs.
- **Key Finding:** Built-in validation criteria (e.g., `age >= 0`) prevents negative ages from entering the database. This is a critical step in ensuring data validity and accuracy before analysis even begins.
