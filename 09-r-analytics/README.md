# R Analytics Projects

## 1. Descriptive Statistics in R
- **Objective:** Calculate descriptive statistics (Mean and Median) for a list of patient temperatures using R.
- **Skills Used:** R syntax (variables, vectors), `mean()`, `median()`, and printing to the console.
- **Key Finding:** The mean temperature is 99.84 and the median is 99.5. 

## 2. Sales Analysis with dplyr (R)
- **Objective:** Load a CSV, group by region, and calculate total commission using the R `dplyr` package.
- **Skills Used:** R `read.csv()`, the pipe operator (`%>%`), `group_by()`, and `summarise()`.
- **Key Finding:** The output matches the SQL and Pandas results (North: 5600, South: 3000, East: 2500, West: 1050).

## 3. Data Visualization with ggplot2 (R)
- **Objective:** Create a bar chart to visualize commission payouts by salesperson.
- **Skills Used:** `ggplot2` grammar of graphics (layers: `ggplot`, `geom_bar`, `theme_minimal`, `labs`).
- **Key Finding:** Successfully visualized the highest earner (Eve: $4,250) and the lowest earner (Diana: $1,050) in a clean, presentation-ready format.
