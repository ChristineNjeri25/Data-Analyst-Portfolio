# Python & R Projects

## 1. Hospital Fever Checker (Python Fundamentals)
- **Objective:** Write a Python script to iterate through patient temperatures and flag potential fevers (>= 100.4F) for doctor alerts.
- **Skills Used:** Variables, Lists, `for` loops, `if/else` conditional logic, and f-strings.
- **Key Finding:** The script correctly identified 2 out of 5 patients needing medical attention.
